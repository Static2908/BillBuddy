# BillBuddy 10–14 Day Solo Roadmap

- **Days 1–2:** Complete project baseline and implement core bill CRUD APIs with validation.
- **Days 3–4:** Add request validation hardening and JWT-based authentication/authorization.
- **Days 5–6:** Build React bill management flows and dashboard screens with API integration.
- **Day 7:** Implement deterministic anomaly detection rules for usage and cost changes.
- **Days 8–9:** Add curated knowledge-base retrieval and LLM-generated anomaly explanations.
- **Day 10:** Strengthen tests, add security checks, and close reliability gaps.
- **Day 11:** Add Docker support and deploy to a target environment.
- **Days 12–14:** Fix integration issues, finalize docs, and prepare demo script/assets.
